## Direction contract

THESIS: the manual page as the interface — the reader's own command set as a synopsis, each documented token resolving to a hanging definition entry; it refuses the dashboard-of-frosted-cards arrangement.

OWN-WORLD: Tokyo Night paper (#16171f wash, ink #eef0f6) carrying fauzuwan.my's faces — Orbitron for display and labels, Ubuntu Sans for prose, system mono for commands; each token owns a neon role colour (green tool, purple option, cyan syntax, red gap) which draws a routed connector into a dot beside its entry. Entries sit in role-tinted panels set in 120px from the page edge; routes leave into whichever margin is nearer, and hovering a token or panel dims and blurs the rest while its own route is the only one left visible. Frosted glass only on the command slab. No persistent navigation bar. NO RULES AND NO UNDERLINES anywhere: no hairline, no frame, no underlined link. Space, colour and weight carry the structure; the only strokes are the routes and the frames around the controls.

STORY: the reader recognises their command as a printed synopsis, clicks a token, and reads the sentence that defines it; then asks for a command in plain language, fresh or adapted, knowing which parts are documented.

FIRST VIEWPORT: a centred Orbitron wordmark with a shell mark and a sans deck; a 900px rounded glass command slab with a blue-to-cyan pill; a quiet status row; a contents sheet of hex-marked tool terms; the centred synopsis with bracket routes; role-tinted entries in the page column with a routing margin each side.

FORM: documentation sheet, chosen over an instrument console and a light-paper reversal from the three offered worlds. seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
